# Web-Fotoalbum mit Kartenansicht

Eine einfache, rein clientseitige Web-Anwendung zum:

- Erstellen von Foto-Ordnern
- Hochladen von Bildern pro Ordner
- Auslesen von GPS-Daten (EXIF)
- Anzeigen der Fotopositionen auf einer Karte (Leaflet + OpenStreetMap)

## Start

Öffne einfach `index.html` im Browser.

> Hinweis: Die Karte nutzt Online-Kacheln von OpenStreetMap.
